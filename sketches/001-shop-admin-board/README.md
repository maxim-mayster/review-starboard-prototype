## Variant: Shop admin board

### Design stance
A practical office dashboard where the review logger and the monthly leaderboard live on one screen.

### Key choices
- Layout: left-side entry panel plus right-side leaderboard/dashboard
- Typography: bold, large operational headings for at-a-glance use
- Color: dark blue with orange accents to feel service-business friendly
- Interaction: add-star demo, store filter toggle, reset demo button

### Trade-offs
- Strong at: showing both data entry and leaderboard in one place
- Weak at: denser than a pure TV board, so less dramatic from far away

### Best for
- Office/admin use where one person logs reviews and the team occasionally checks rankings
